# LTE Telemetry & Video System

LTE-based communication system for video transmission and MAVLink telemetry in UAV/UGV platforms.

## Project overview

The project was designed as a lightweight and modular communication environment for mobile and unmanned platforms.  
It enables video streaming, telemetry transmission and remote access through LTE and overlay VPN networks.

## Main technologies

- Raspberry Pi
- LTE modems
- Linux
- ZeroTier
- MAVLink Router
- ffmpeg
- rpicam-vid
- UDP / TCP
- SRT
- Bash automation

## Features

- Low-latency video transmission
- MAVLink telemetry routing
- LTE communication
- ZeroTier overlay VPN access
- Remote device monitoring
- Automatic reconnect after connection loss
- Support for multiple receivers
- Linux-based autostart and watchdog logic
